    포함 항목과 별도 비용

    본체 구성: CPU, 그래픽카드, 메모리, 저장장치, 메인보드, 파워, CPU 쿨러, 케이스

    별도 확인: 운영체제, 프로그램 라이선스·구독료, 모니터, 키보드·마우스, 조립비, 배송비, 무선랜·블루투스 장치, 추가 팬과 케이블, 외장 저장장치·백업 장치

    방송 장비: 마이크, 오디오 인터페이스, 웹캠, 캡처보드, 조명 등은 포함하지 않습니다.

    기본 쿨러 사용 구성은 실제 CPU 판매 상품의 쿨러 포함 여부를 확인하세요. 미포함이면 별도 쿨러 비용이 필요합니다.

    이용 안내

    • 표시된 부품은 예시입니다. 구형 제품의 재고나 가격이 불리하면 같은 용도에 맞는 신제품·대체 제품과 비교하세요.
    • 가격은 자동 수집하지 않습니다. 모든 부품 가격을 입력하기 전에는 전체 합계와 예산 충족 여부를 확정하지 않습니다.
    • 게임 사양은 최신 공식 정보와 대조하지 않은 참고 데이터입니다. 작업용 안내는 공식 최소·권장 사양표가 아닙니다.
    • 입력 가격과 기준일은 프로그램·예산·구성별로 이 브라우저에 저장됩니다. 다른 기기와 동기화되지 않습니다.
    • 브라우저 데이터 삭제, 비공개 모드 또는 저장 제한으로 저장값이 사라질 수 있습니다. 판매처에 입력값을 전송하지 않습니다.
