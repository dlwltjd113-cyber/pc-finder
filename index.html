    게임 최소·권장 사양

    공식 안내 확인

      공식 게임 사양과 이 사이트의 추천 PC 구성은 별개의 정보입니다. 표시된 사양은 게임 업데이트에 따라 달라질 수 있습니다. 구매 전 링크에서 최신 요구사항을 확인하세요.

      포함 항목과 별도 비용

      구성에 포함: CPU, 그래픽카드, 메모리, 저장장치, 메인보드, 파워, CPU 쿨러, 케이스

      별도 확인: Windows 등 운영체제, 모니터, 키보드·마우스, 조립비, 배송비, 무선랜·블루투스 장치, 추가 팬과 케이블

      기본 쿨러를 사용하는 구성은 CPU 상품의 실제 쿨러 포함 여부를 확인하세요. 미포함 상품이면 별도 쿨러 비용이 필요합니다.

      주의사항

      • 본 페이지는 실시간 판매 견적이 아닌 참고용 구성입니다. 오래된 제품의 재고나 가격이 불리하면 대체 제품을 비교하세요.
      • 표시된 예산 안에 구매할 수 있다는 보장은 없습니다. 가격을 모두 입력하기 전에는 예산 충족 여부를 판단하지 않습니다.
      • CPU 소켓, 메모리 규격, BIOS, 부품 크기, 파워 용량과 커넥터를 실제 모델 기준으로 확인하세요.
      • 게임 성능은 해상도, 그래픽 옵션, 드라이버, 업데이트 및 실행 중인 프로그램에 따라 달라집니다.
      • 입력한 가격은 이 브라우저에 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터 삭제 시 사라질 수 있습니다.
